# Спецификация REST API: Сущность "Пост" (Post)

## Описание полей сущности
| Поле | Тип данных | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `id` | string (UUID) | Генерируется сервером, уникальное | Уникальный идентификатор поста |
| `author_id` | string | Обязательное, не пустое | Идентификатор автора (из Identity Service) |
| `clan_emoji` | string | Обязательное, 1 символ | Эмодзи клана автора (для фильтрации) |
| `content` | string | Обязательное, от 1 до 280 символов | Текст публикации |
| `created_at` | string (ISO 8601) | Генерируется сервером | Дата и время создания |

## Спроектированные операции (CRUD)
| Метод | Путь | Назначение |
| :--- | :--- | :--- |
| **GET** | `/posts` | Получение списка постов (с пагинацией `page`/`limit` и фильтром `clan_emoji`) |
| **GET** | `/posts/{id}` | Получение конкретного поста по его ID |
| **POST** | `/posts` | Создание нового поста |
| **PUT** | `/posts/{id}` | Полное обновление текста поста |
| **DELETE** | `/posts/{id}` | Удаление поста |
